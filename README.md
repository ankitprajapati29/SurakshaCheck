## 💡 About the Project

SurakshaCheck is an AI-powered digital safety assistant that helps users analyze suspicious messages and links to identify common scam indicators.

By combining rule-based detection with AI-generated explanations, it aims to make online safety easier to understand and more accessible.

Instead of simply flagging a message, SurakshaCheck helps users understand **why it may be suspicious and what precautions they should take.**

## ✨ Key Features

| Feature | Description |
|---|---|
| 🔎 Scam Detection | Identify common warning signs in suspicious messages |
| 🤖 Gemini AI Analysis | Generate additional explanations and safety guidance |
| 📊 Risk Assessment | Display a risk score and detected indicators |
| 🔗 URL Inspection | Identify links and flag suspicious URL signals |
| 🖼️ Screenshot Input | Extract text from screenshots using OCR |
| 🎙️ Voice Input | Provide message input through voice transcription |
| 🌐 Hindi & English | Support a more accessible user experience |
| 🔊 Text-to-Speech | Listen to results and safety recommendations |
| 📱 Responsive UI | Use the application across desktop and mobile screens |

## ⚙️ How It Works

**01 — Submit**

Paste a suspicious SMS, WhatsApp message, or link, or provide supported screenshot or voice input.

**02 — Analyze**

The application checks the message using local detection rules and requests additional analysis from the backend AI service.

**03 — Understand**

Review the risk score, warning indicators, and AI-generated explanation.

**04 — Take Precautions**

Use the recommendations to help decide how to verify the message safely.

## 🔐 Privacy & Responsible Use

- Local rule-based checks run in the browser.
- Message content submitted for AI analysis is sent to the backend service.
- Do not submit passwords, OTPs, UPI PINs, or sensitive banking information.
- Detection results are preliminary and may be incomplete or inaccurate.


## ⚠️ Disclaimer

SurakshaCheck is a digital safety awareness tool. It does not guarantee that a message, URL, or website is safe or fraudulent. Always verify important requests through official channels.
